# 内容数据

本目录预留设施、改建配方、敌人、行动组、地图与场景的UTF-8 JSON数据。采用System.Text.Json解析、强类型定义与语义校验；格式版本、稳定ID及每局冻结规则见[技术架构](../docs/design/技术架构.md)。目前不把文档数值转换成未经校验的数据文件。

内容使用稳定ID；类型定义与运行实例分离。足迹、地形条件、源/汇/无线覆盖/远程传输能力可以组合，不能把“一个格子是一座塔”或“每塔只能有一种能源角色”写进格式。

内容ID、首批职责与分期以[初始塔与敌人集合](../docs/design/初始塔与敌人集合.md)为依据，基础参数以[试跑配置](../docs/design/试跑配置.md)为依据。真实电网和储能场景另按[核心系统约定](../docs/design/核心系统约定.md)建立，测试供能不是正式零能耗配置。候选机制登记不等于已进入内容库。
