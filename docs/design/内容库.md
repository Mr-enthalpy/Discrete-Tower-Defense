## 工业道路消耗物

| ID | 名称 | 生命周期与效果 |
| --- | --- | --- |
| bomb.standard | 炸弹 | 自耗生命，归零标准范围爆炸 |
| bomb.shock | 震荡弹 | 自耗生命，较低伤害、较广麻痹 |
| bomb.fragmentation | 破片炸弹 | 自耗生命，较小高伤区，事件参数独立定义 |
| bomb.mine | 地雷 | 无自然自耗，敌人接近触发 |

四种均是便宜、同类卡长部署冷却的消耗物，通常道路非阻挡、拒绝所有回血、不可售卖；战斗归零只爆一次，换卡不洗冷却，黎明不复活。

## 普通军团与异常

依据[用户修订 0003](../decisions/0003-敌人体型与白天保留战场.md)，下表 ID 代表类型，不代表唯一体型。每种类型另定义支持的体型变体及数值；不存在的组合禁止生成，不要求全尺寸分布。生命、伤害等修正和碰撞/净空规格显式配置，具体档位、倍率和各兵种分布待调；精英身份不自动等于大型。波次、军团和补员选择真实合法变体，原有普通/异常资格不变。

| ID | 普通敌名 | 职责 |
| --- | --- | --- |
| enemy.marcher | 行军体 | 规则推进、独立实体，短列为软偏好 |
| enemy.rusher | 突进体 | 快速轻单位 |
| enemy.rammer | 撞击体 | 重甲接触压线 |
| enemy.siege | 攻城体 | 中远程直射，天气/高度/LOS/前排可影响 |
| enemy.lobber | 曲射体 | 弧线压高地，仍受观测条件 |
| enemy.repairer | 修复体 | 有限治疗自身及附近；不回甲、层盾、不复活 |
| enemy.shielder | 护盾体 | 限定邻近目标、总产率和单体层数上限 |
| enemy.inspirer | 鼓舞体 | 近战推进、远战频率，不默认提高补员/恢复吞吐 |
| enemy.replenisher | 补员体 | 向组目标人数补行军体，预算/速率/合法出生点有限 |

污染普通敌人仍用同一兵种 ID＋C 状态，其攻击传播污染，洗净后停止传播；不复制成另一套单位库。

| --- | --- | --- |

所有异常由全局非实体指挥团管理，但单位自身有真实位置、耐久、暴露与撤退；高阶元技能受并发和恢复窗口约束。普通路线必须有时间、火力或工程应对机会。

首批取舍和验收见[制作切片](../plan/制作切片与验收.md)。本登记没有把每项都放进 A，也没有把标准库里的机制降成可忽略候选。
