# 设计基线摘要

来源：[v1.0 原文](../baseline/v1.0/README.md)。本页为导航性摘要，完整细节与默认解释分别见 PDF 对应章及第 11 章；不得用摘要缺项否定原文。

## 体验与术语（第 00–01 章）

前期投资，后期维持体系。经济与战斗压力分别设计；经营、防御组织、综合扩展、旧工业遗产、神秘遗产、特殊挑战各自验证。数量压力仍保留，并与持续补员、支援、远程和异常压力组合。纯工业、纯神秘、混合共享核心、金币和基础电网；P5 标准关必须有可玩的纯工业解。

| 状态 | 范围与意义 | 不得混用 |
| --- | --- | --- |
| T | T0–T3，工程权限及常规 V 上限 | 不是神秘等级 |
| M | M0–M3，已获得的神秘权限 | 不是制作阶段编号 |
| P | P0–P5，单局不可逆世界污染 | 不是局部可清洗污染 |
| Q | 当前全局神秘值库存 | 不是电能，不等于累计总收入 |
| V | V0–V3，设施成熟度 | 满级材料恒指最终 V3 |
| A | 稳定锚可完整抑制的环境能力规格 | 不是第五条科技树 |
| C | 单个设施或普通敌人的局部污染 | 与 P、HP、护甲、层盾各自保存 |

五个递增 Q 库存阈值：前三推进 M/P，后两只推进 P。入账立即检查，可跨多档；消费不撤回历史等级。初始 M/P/Q 独立配置。核心生产金币与启动电力、提供覆盖和 T 入口，不生产 Q。世界升级立即发生；新增异常通过预告窗口进入，当前已预告技能不临时升级。

关前公开完整地图、扩展顺序、入口、地形、初始资产状态、天气、日程、M/P/Q、敌人池和换卡节点。开放的是可用空间，不以致命未知信息制造突袭。卡槽选择基本设施、武器、炸弹和单个仪式成员；升级及护盾 V3 分支不另占卡。换卡不删除已建设施，也不停止其工作或升级；新建和融合输出仍需当前卡权限。

## 空间、炮位与天气（第 02、04 章）

实际高度、移动通行、普通建设、仪式/炸弹部署许可、标签是独立维度。高地通常阻地面敌人，但不统一禁止塔。视线用炮口—目标高度与沿线地形判断；上坡有有效距离成本，下坡没有通用伤害加成；曲射轨迹与目标观测条件分离。

1×1 与 2×2 设施均是单个受击实体；四格融合要求等实际高度。支撑墩既承载火炮/迫击炮，又可作巨炮后靠；人工规格不改变地形或炮口高度。炮与墩安装后合成受击及投资整体。巨炮背侧两格要求高于炮位的天然地形或合格人工支撑，可混用。视图旋转和世界朝向分开。

晴、阴、雷雨同时影响敌我；夜间太阳能与月光吟诵按天气定义。人工天气覆盖期间自然时钟继续，结束回归自然状态。引雷节点只改落点，不增加雷次数或提供免伤。雷击是中立范围伤害＋有限总能量脉冲，以命中前网络快照交换，随后提交伤损断网；脉冲接收能力独立于普通汲取速率。

## 三种用能与伤害语义（第 03 章）

本地区源汇交换不占远程转供额度；跨区节点向外的总量受限。重叠覆盖不复制真实端点，普通消费者不成为无限转发桥。默认按同一实际瓶颈中有效需求的**同一满足比例**分配，不按相同瓦数、不按实体编号抢占、无手工优先级。满储或无需求退出。电池只使用真实余量，充/放/待机互斥。

| 曲线 | 行为 | 缺能反馈 |
| --- | --- | --- |
| 固定单发能量 | 冷却完成＋能量足够＋目标/射界合法才扣能发射 | 间隔增长，单发保留标准效果 |
| 电塔固定节拍 | 有限储能，窗口到来按实际释放能量形成伤害预算；无目标保留能量，节拍继续 | 威力下降；零能量无有效攻击；首次等完整周期 |
| 静电持续负载 | N 个合法目标请求 Np，所有目标效果乘同一实得比例 | 全体一起降效，不挑部分目标满效 |

电塔只有击杀且剩余预算才向附近下一目标溢出，同次各目标一次；无跳数帽、无逐跳衰减，防护耗散也消耗预算。炮兵的一发可以产生多个独立爆炸事件，各事件按实际发生时位置完整结算真 AOE；不同事件可重复命中同敌。巨炮是有限寿命直线穿透，同弹同敌一次，山体阻断；不附加万能爆炸包。

普通伤害在当前层盾截断，破最后一层溢出也损失。狙击、电塔、静电声明穿层；咒杀绕盾且自身绕甲，不给友军破甲。祛除真伤绕普通层盾和护甲，仍服从适用异常防护。异常减伤、单包上限、共享受伤频率窗、免疫分别定义，不能合成一个通用“护盾”。献祭/吞噬为有对象资格和名额的特殊移除，不套普通伤害包。

## 神秘生产、污染与生命周期（第 05–06 章）

转经轮消耗电力生产 Q。中性诵经阁装典籍，同族多个阁共同推进**全局一个准备槽、最多一个就绪资格**；准备完成暂停成本。部署消耗资格和公开成员费用，失败无消费。最后一张家族卡移除时阁回中性、保留暂停进度；恢复不复制资格。

终结仪式自耗 HP，战斗内归零触发一次，敌伤可提前、治疗可延后；维持召唤落地生效、HP 归零离场，治疗可延寿。炸弹拒绝回血；仪式、炸弹不可出售。融合消费仪式不同时发动原效果。永久设施损坏留残骸与占位、停止阻挡；黎明恢复可复苏设施，保留 C、能量和合法成长历史；不复活耗物或免费续召唤。

P 决定环境，C 决定局部失控。稳定锚只压环境增长，不去已有 C、不免疫主动污染；重叠取最强有效规格。T3/V3 工业链必须能满足 P5 稳定能力。维修的 HP 与 C 共用预算；高污染无锚时存在单目标可接受校准上限，不能靠无限叠维修永远自稳。净化塔抽取友方真实 C 回收 Q；祛除敌方污染不产 Q。融合按最大生命权重继承伤损和 C，不能洗状态。

## 敌人与玩家控制（第 07 章）

普通敌人用功能“XX体”名称，普通军团负责局部任务；个体仍独立受击和移动、共享导航。异常指挥团无实体，负责全局预算、投放、并发、技能错峰和恢复窗口；真实异常实体必须接近、暴露、施法、撤退，击杀/打断有喘息。

盲目、迷乱、缄默的高影响窗口由排程限制。P3/P4 元轮次替换一次普通作用，P5 特殊轮次才同步全场普通效果。预告锁定范围/强度，打断不冒充一次完成。盲目隐藏精确数值但战场真实；迷乱拒绝工程命令而非排队；缄默禁止对应准备/部署，保留已就绪资格和已存在仪式。暂停、相机、设置、退出、辅助选项始终可用。

## 美术与呈现（第 08 章）

二维构成主义＋功能主义：典雅、柔和、细腻、符号化。工业、神秘共享图元和材料；污染通过相位、曲率、连接、重复的连续变化体现，原设施始终可辨。普通敌人靠功能构件识别，异常把概念符号变为器官。不是旧版灰白极简图标和数学敌名的延续。

P 改 UI 装饰与 BGM 层，正常污染不移动热区、不伪造余额；真实元攻击按模拟授权改变信息或命令。缄默只改对应声部，不消音警告。资产优先代码/矢量/参数几何，保存可编辑源、参数、生成方式、来源；运行变形不改碰撞。降低闪烁和抖动只影响呈现。
