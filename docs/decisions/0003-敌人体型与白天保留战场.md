# 0003：敌人体型与白天保留战场

状态：2026-09-25 用户明确修订，优先于设计基线 v1.0 中冲突条文。原始 PDF/DOCX 和转录正文保留原样，当前实现须合并本修订阅读。

## 敌人类型与体型

同一类型可以有多种体型；每个类型只配置实际支持的体型集合，不要求所有类型都有所有体型。例如部分基础类型可以没有大型，部分精英类型可以没有小型。这是允许的内容结构，不是本轮给具体兵种锁定分布。

体型影响数值，而不只是图像缩放。类型负责职责和能力，体型变体负责该组合的数值参数及实际几何。生命、伤害、速度、护甲等哪些字段改变、改变多少，由内容表明确配置，不假定所有属性同倍增长或大型必然更快。体型不替代普通/异常身份、污染或能力资格；小型异常仍不因此可献祭/吞噬。

使用类型 ID＋体型变体 ID 选取真实存在的组合。军团、波次和补员引用合法变体，可按场景给不同权重；缺失组合报错，不自动补齐或回退。类型保持同一功能轮廓，体型表现与规则几何相符；碰撞和控制判据不读取视觉 scale。需要净空区分时，共享导航缓存纳入净空规格，仍由相同需求的单位共用。

## 白天与黎明

进入白天停止刷怪，并恢复场上已被破坏的非一次性塔；**不移除已存在的敌人**。这是阶段转换的一次恢复，不是整个白天持续免费复活。未被破坏的受伤设施不因这条规则自动补满；核心致死仍先判失败。

保留敌人的位置、HP、甲盾、C、控制、军团任务及异常施法进度，照常推进白天战斗。既有弹体、区域、关系与已预告效果按自身条件继续，不因换日清除。恢复不增加能量/Q、不洗 C、不重置成长历史；一次性塔、已消费仪式与临时召唤不复苏。

关卡波次和异常新增投放使用白天停刷门禁，上一夜过期投放不在白天补发。停止投放与清空实体必须为不同操作；存活异常仍占在场预算，次夜投放不能将其忘记。阶段变化不重置其技能轮次、恢复窗或预算账。

本修订取代原文 1.3 的黎明清理敌军/飞行效果，以及 11.4 敌人黎明清场等相关说法。重开、卸载和显式终局清理仍是非战斗移除原因，不能拿来实现日常黎明。

## 需在实现前补定的边界

- “停止刷怪”确定禁止关卡与异常调度新增投放；补员体、门扉、死亡分裂等战场内派生是否同样受限，尚未指定，生成请求必须携带来源以支持明确决策。
- 残骸上可能站有敌人。复苏恢复阻挡前需要明确重叠处理；不得借复苏删除敌人、触发免费伤害或把单位永久封住。
- 最终夜后采用到时存活胜利还是清完残敌胜利，独立于日常黎明保留敌人，需在关卡胜利条件中明确；本轮不擅自新增清敌胜利要求。

上述待定不影响已确认规则，也不能作为恢复旧黎明清场的理由。验收见[制作切片与验收](../plan/制作切片与验收.md)。
