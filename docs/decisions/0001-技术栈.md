# 0001：桌面版技术栈

状态：方向保留；2026-09-25 按基线 v1.0 第 10.2 节修订。旧文全文见[归档](../archive/pre-baseline-v1/decisions/0001-技术栈.md)。

采用 Windows 桌面优先、Godot .NET＋独立纯 C# Simulation。Godot 负责输入、窗口、二维表现、UI、声音和平台资源；Simulation 拥有单局、规则、账目与命令验证。Content 加载强类型只读定义，规则值不复制到 Godot 场景。

保留固定步、单线程正确性优先、连续实体数据、共享导航、空间查询、可脱离引擎的规则运行器。初期不建设完整 ECS、任意脚本、全局消息框架或第三方依赖注入体系。初始绘制拟用 Compatibility，批量绘制按实测决定。

**不锁定 Godot、SDK、目标框架或测试包版本。** 旧文的候选版本不构成兼容性证据。工程前置依次验证 .NET 编辑器、SDK、导出模板、纯库引用、headless 与 Windows 导出，以及无开发环境机器启动；通过后记录实际组合并提交版本锁和真实命令。

工程选择：UTF-8 JSON＋System.Text.Json；资产以可复现矢量/程序图形为主；纯规则测试拟采用 xUnit，规则运行器与 Godot 集成验证分开，性能使用 Release 导出。所有选择目前均无执行成绩，不声称版本已安装或通过。

细节见[架构总览](../architecture/架构总览.md)及[制作前置](../plan/制作切片与验收.md)。
