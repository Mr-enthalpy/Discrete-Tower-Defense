# 0002：以设计基线 v1.0 取代旧启动设计

日期：2026-09-25。依据：用户明确指定新 PDF 在冲突时优先。范围：文档、责任目录和未来工程契约；没有导入原游戏实现，也没有实现完整内容库。

## 已处理冲突

| 旧内容 | 当前依据 | 工程影响 |
| --- | --- | --- |
| 金币＋能量，无独立神秘链 | 金币、电力、全局 Q；T/M/P/V/A/C 分离 | 独立账目、权限历史与污染模块 |
| 同瓶颈绝对功率平均 | 同瓶颈有效需求满足比例相同 | 归一化公平求解，测试 10/30 请求而非只测相同请求 |
| 攻击统一单发电容 | 固定单发、电塔节拍预算、静电人数负载 | 能源模型与伤害效果分别组合 |
| 火炮一发单次 AOE | 炮兵独立爆炸事件簇 | 逐事件真范围查询、去重及层盾结算 |
| 链、环、团、星、树 | 九种功能构造体＋十一种概念异常 | 新定义 ID；旧原型没有存档迁移负担 |
| 巨炮消费四个普通基础塔；支柱 | 四座最终 V3 机炮；支撑墩统一基础/后靠 | 实际高度、配方材料等级、投资/伤损/C 继承 |
| 所有配方输入必须在输出占格内 | 祛除采用相邻双输入、输出分解塔原位；仪式显式叠放 | 输入区域与输出足迹分离；配方优先识别 |
| 暂无选卡；仅逐步揭露 | 卡槽与阶段换卡、完整关前情报、区域渐次开放 | 卡权限独立于已有实体运行权限 |
| 灰白极简数学符号为主要风格 | 柔和精细构件、工业/神秘连续变形、P 驱动 UI/BGM | 表现映射和辅助模式，禁止装饰改规则 |
| M0–M4、E1/E3a/E2/E3b | A–F 制作切片 | M/P/V 留给游戏术语，不沿用冲突阶段名 |
| 旧试跑价格、三夜、工程版本与毫秒预算 | 天数和数值待调；工具链必须实测 | 旧表全量归档，不自动继承数字 |

保留 Godot＋纯 C#、Windows 优先、固定步、共享导航、空间索引、实体与占格分离、真 AOE、原子工程操作。旧文完整保留于[归档](../archive/pre-baseline-v1/README.md)，当前入口不再指向它作为规范。

| 待定 | 落地时机与约束 |
