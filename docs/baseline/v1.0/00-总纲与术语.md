## 0.1 核心定位

这是一款二维俯视、方格建造、连续位置战斗的阵地生存塔防。玩家围绕核心建立生产、供电、武器、维修和异常处理设施，在昼夜交替与地图扩展中维持防线。

高压波次保留大量敌人涌来的压迫感。敌人威胁由数量、持续补员、远程火力、局部支援和异常干预共同产生。范围火力可以真实消灭密集杂兵，支援链和高价值单位则让清杂后的战斗继续存在。

工业的优势是稳定、连续、可规划的战斗能力；神秘的优势是有条件的伤害、空间控制和规则干预。两者共享地图上的设施风险，具有不同的资源和时间结构。

核心体验是：前期决定把有限资源变成什么，后期决定怎样让已经建立的体系持续工作。

## 0.2 已确定的设计支柱

### 持续运营

金币支付建设，电网供给工作，空间决定组织方式。高阶塔的数量由完整投资、占地、射界、基础工程和供能能力约束。玩家能够承担体系成本时，可以持续扩张。

### 实体化决策

长期火力、仪式准备、污染处理和异常敌人都具有地图上的实体载体。操作界面负责提出命令，战场状态决定命令能否完成。仪式的全局资源与其局部执行位置分别承担不同约束。

### 条件性神秘

神秘伤害通常依赖作用阶段、区域停留、持续关系或并发目标数。纯神秘允许通关，但需要组织不平滑输出；临时小炮承担最低限度的开局自保。混合防线通过分工降低运营压力。

### 普通组织与异常权限

普通构造体影响附近军团的战斗状态。异常单位由全局异常指挥团统筹，在地图上移动、施法和撤退，能够影响远距离关系、污染和玩家交互。世界污染扩大异常的规则权限。

### 可理解的风险

科技、天气、地形、污染和敌人技能具有可观察的原因与结果。危险可以很强，玩家仍应拥有识别、预备和响应窗口。失去局部控制是战斗事件，软件的暂停、设置和退出权始终由玩家保有。

### 连续的视觉身份

正常工业、神秘工业、污染设施、普通敌人和异常敌人共享一套柔和、精细的几何构件。功能关系逐渐失配，形成连续的不安，而不是靠粒子数量制造强度。

## 0.3 世界观口径

神秘是对非常规知识与关系的利用。污染表示局部设施或整个环境超出当前体系的承受能力。净化、稳定和维修处理的是工程可控性，而非道德归属。

玩家侧可直接使用宗教、仪式与器物符号，如转经轮、经书、法坛和家族典籍。异常敌人以“盲目、缄默、浸染”等状态概念命名。不安主要来自敌方符号、污染过渡和失控后果。

## 0.4 统一术语

| 术语 | 定义 |
| --- | --- |
| 科技等级 T0—T3 | 核心升级获得的工程权限，决定内容解锁和常规设施强化上限 |
| 神秘等级 M0—M3 | 玩家已经掌握的神秘权限，神秘值突破阈值后自动提升，本关保留 |
| 世界污染 P0—P5 | 全局环境状态，影响污染压力、异常投放与能力；本关单向提升 |
| 神秘值 Q | 当前可消费的全局资源库存，生产、抽取和泄露入账，吟诵与作用消耗 |
| 设施等级 V0—V3 | 单个设施的成熟程度；高阶融合结果通常重新从 V0 开始 |
| 稳定规格 A | 稳定锚能够完整压制的环境档位；它是能力值，不是第五种科技 |
| 局部污染 C | 单个设施的失控进程，或普通敌人携带的污染程度 |
| 射界 | 作用距离、朝向扇区、地形视线等条件的组合；文中具体说明是哪项变化 |
| 真范围伤害 | 每个范围事件对当时区域内所有合法目标独立结算，目标数不摊薄该事件伤害 |
| 普通层盾 | 敌方多层薄盾，一般伤害在当前层截断溢出 |
| 电能护盾 | 玩家基础护盾在 V3 的工业分支，以电力恢复容量式防护 |
| 拒止立场 | 玩家基础护盾在 V3 的神秘分支，以区域阻滞和有限减伤防护 |
| 支撑墩 | 同一种基础设施，既可承载炮位，也可提供人工后靠高度 |
| 仪式族准备 | 由诵经阁共同推进、最多保有一份就绪资格的家族进度 |
| 军团 | 普通单位的任务组织；成员仍是独立战斗实体 |
| 异常指挥团 | 无实体的统筹层，控制异常单位投放、组合和施法排程 |

## 0.5 设计状态的表达

本文采用四种状态：核心决定、闭环约定、待调参数、后续扩展。大方向与正式名称在核心文档中维护；为落地补足的具体解释集中登记于《11 规则索引与补足约定》。

数值只在能够检查规则时使用关系式。具体塔价、敌人生命、冷却秒数、世界阈值和首发关卡数量由平衡原型确定。科技与神秘的上限、配方尺寸、仪式解锁级别等内容结构属于当前设计本身。
