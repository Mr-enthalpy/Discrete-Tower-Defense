## 11.2 已确定的核心关系

工业以金币建设、电网运营，神秘以全局Q和实体吟诵组织。科技最高T3，神秘权限最高M3，世界污染最高P5。世界升级自动、不可逆，局部污染可被处理。

支撑墩统一承担炮位基础和人工后靠。火炮、迫击炮先有墩，再形成成熟炮位；重炮、岸炮融合继承基础。巨炮后靠按方向检查更高天然地形或人工支撑。

护盾的电能与拒止是V2到V3的两个方向。诵经设施统一为中性的诵经阁，以当前仪式卡决定可装典籍。

普通敌人使用“XX体”功能命名，异常保留抽象状态名。普通军团局部协作，异常由全局统筹，危险单位需要真实位置和施法窗口。

火炮族使用独立爆炸事件簇，电塔固定节拍与可变能量，静电按人数请求功率。敌人普通防护为多层薄盾；神秘输出保留条件性与非平滑结构。

## 11.3 本包采用的闭环约定

以下是为避免跨系统歧义而采用的默认解释，属于可修订的设计细节，不是已经验证的最优数值。

| 项目 | 默认解释 |
| --- | --- |
| 初始M与P | 关卡可分别设置；世界已污染与玩家已掌握知识不是同一事实 |
| 库存阈值 | 使用当前Q曾达到的档位；入账先检查阈值，消费不回退历史 |
| 常规V上限 | 随T开放；“满级材料”指最终V3，而非当前可达最高级 |
| 锚的等级差 | A为独立能力规格，T3/V3工业链能够完整应对P5 |
| 炮与墩 | 安装后作为一个受击主体和投资整体，保留基础规格信息 |
| 复合集成成本 | 以完整累计支出比较，稳定中继高于同规格独立供电塔与锚之和 |
| 视图旋转 | 只改变屏幕方向；朝向与配方另有明确世界坐标变换 |
| 层盾最后一层 | 一般伤害破最后一层后的溢出也耗散，穿层攻击才继续到本体 |
| 祛除真伤 | 绕过普通层盾和护甲；适用的异常限伤、频率与免疫仍按明确定义执行 |
| 雷击充能 | 普通汲取上限与脉冲接口分开，所有注入共享有限总能量 |
| 引雷角色 | 供电塔系及复合节点引雷；具有局部覆盖并不自动等于引雷节点 |
| 电塔无目标 | 保留有限储能，固定机械节拍继续；下一合法窗口出手 |
| 月光吟诵 | 提高工作速率，按完成工作收取成本，瞬时Q需求同步上升 |
| 人工天气 | 保持公开时段，期间自然天气时钟继续，结束后回归自然状态 |
| 仪式费用 | 家族准备费用与成员发动费用可以并存，均在界面提前显示 |
| 仪式转型 | 家族无卡时阁回中性、准备暂停保留；没有可用成员则不可放置 |
| 融合仪式材料 | 作为组件被消费，不同时触发通常的归零仪式 |
| 非伤害移除 | 献祭与吞噬有独立合法对象，默认按战斗死亡处理派生 |
| 召唤与维修 | 标准临时小炮、路障可回血维持；炸弹拒绝所有回血 |
| 污染维修上限 | 无锚高污染限制单目标可接受校准速率，避免无限堆叠自动解题 |
| 残骸历史 | 黎明恢复生命，不清空局部污染、储能账目或万魂幡历史 |
| 神秘祛除配方 | 暂取相邻两塔融合、输出落在分解塔位置，输入由预览明确列出 |
| 拒止权限 | 默认M2且满足V3工程上限，具体档位在路线验证后锁定 |
| 普通鼓舞 | 近战推进和远战频率，不自动提高补员或恢复的产出 |
| 否认原型 | 先采用短暂状态免疫，其他免疫类别作为独立后置变体 |

## 11.4 生命周期对照

| 对象 | 自然衰减 | 接受回血 | 归零结果 | 黎明处理 |
| --- | --- | --- | --- | --- |
| 永久普通设施 | 无 | 是 | 残骸、停工、停止阻挡 | 按关卡规则复苏，保留独立状态 |
| 炸弹、震荡弹、破片炸弹 | 稳定自耗生命 | 否 | 爆炸一次并消耗 | 已消耗者不恢复 |
| 地雷 | 无自损，接近触发 | 否 | 爆炸一次并消耗 | 已消耗者不恢复 |
| 终结型仪式 | 自耗生命 | 是 | 发动一次并消耗 | 不作为普通残骸复苏 |
| 维持型小炮、路障 | 自耗生命 | 是 | 作用结束、离场 | 无普通复苏，也不免费补寿命 |
| 敌人 | 按状态与伤害 | 由敌方能力恢复 | 战斗死亡及合法派生 | 清场移除，不触发死亡派生 |

出售、融合、重开和关卡卸载不是普通战斗死亡。它们不得触发误爆、重复献祭或召唤奖励。
