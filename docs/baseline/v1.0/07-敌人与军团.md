## 7.1 三层敌人身份

普通构造体以功能命名，主要改变附近军团的战斗状态。污染构造体仍属于原兵种和普通军团，只是携带污染并发生视觉失配。异常单位属于独立的全局异常指挥团，干预战场规则和远距离关系。

正常—污染—异常在美术上连续，在战斗资格上明确。普通单位不会仅因污染很高就自动获得异常指挥身份，异常单位也不能被一次净化洗成普通兵。

## 7.2 普通军团

军团行动组决定任务、目标区域、路线策略与角色安排；共享导航为相容需求复用方向信息。个体负责连续移动、局部避让、接敌、受击和死亡。

队形是软偏好，避障、合法碰撞和生存状态优先。前排、远程、修复、补员可以保持不同停距，但不要求所有成员精确占一个刚性槽位。

军团可以推进核心、攻击已预告的能源节点、在区域集结或重新寻找突破口。失去组目标时执行明确后备任务。一次波次可以包含多个军团；一个军团失效不连带删除其独立成员。

## 7.3 九种普通构造体

| 名称 | 职责 | 主要活动构件 |
| --- | --- | --- |
| 行军体 | 大量基础近战兵 | 中轴、成对侧件，规则伸缩和转动 |
| 突进体 | 高速轻型突击 | 收束的纵向轮廓，快速而稳定的构件节奏 |
| 撞击体 | 高生命、护甲前排 | 厚重前部承力板，接敌回冲 |
| 攻城体 | 中远程平射设施攻击 | 长轴炮架，停稳后展开 |
| 曲射体 | 抛射攻城和高地威胁 | 上抬臂、配重和折叠构件 |
| 修复体 | 局部生命恢复 | 修复臂向受援对象转动和连接 |
| 护盾体 | 为附近单位补充层盾 | 生成并转移的薄环、弧片 |
| 鼓舞体 | 提高局部近战冲锋和远程射击节奏 | 规律展开的节拍构件 |
| 补员体 | 持续维持基础兵员厚度 | 开合装配腔，推出新行军体 |

### 行军体

构成敌潮主体，生命、速度和近战节奏直接可读。短列只是组织形式，每个成员仍独立受击。它们可以被持续补充，因此真范围火力承担长期清杂，而非一炮清完后永远暴露支援单位。

### 突进体

利用射击空窗、分散炮击和薄弱方向快速进入近线。较低生命使稳定持续火力有价值，移动速度使长读条区域攻击更难充分覆盖。污染后可迅速把附着威胁送到深处。

### 撞击体

较大体型、高生命、明显可破坏护甲，承担接触破障。受到麻痹后仍较倾向推进，方向扰动不取消其基本攻击。它为狙击破甲、单体持续火力和高血量阶段神秘伤害提供考题。

### 攻城体

进入中远程有效距离后停止，向玩家设施发射平射弹体。受天气、高差和真实地形射线限制。攻击可以被前方合法阻挡体承接，因此防线结构仍有价值。

### 曲射体

以较慢周期投射弹头，威胁山后和高地设施。越障与观察分开，默认仍受天气获敌范围影响。弹道时间提供移动和结构调整的窗口；它不是无预告全图点伤。

### 修复体

在自己及附近友军之间使用有限总生命恢复预算，优先可理解的受损对象。目标增多不凭空扩大总治疗。默认不恢复护甲、不补层盾、不复活，保持与其他支援职责区分。

### 护盾体

周期性为附近有限对象补充低值盾层，单目标层数上限与总补盾速率公开。一般伤害在一层中截断，迫使慢炮付出攻击次数；穿层电击、狙击和高频持续攻击提供解法。

### 鼓舞体

局部提高近战推进和远程攻击频率。鼓舞不会改写全场导航，也不同时抬升所有恢复、补员和生产能力。范围、对象和节律保持稳定，杀掉它产生可察觉的节奏变化。

### 补员体

在身边合法地面持续生产低级行军体，维持本军团目标规模。速率和在场预算有限，不生产高级支援或异常单位。生成空间拥挤时延后或选择附近空位，不把单位重叠挤成不可读团块。

击杀补员体结束后续补员，已生成成员继续执行普通任务。生产不会重置整支军团状态或复制已有支援。

## 7.4 典型普通军团

| 组合 | 玩家需要处理的问题 |
| --- | --- |
| 行军体＋补员体 | 持续清杂和对补员源的火力投入 |
| 撞击体＋修复体 | 破甲、有效单体伤害与治疗时机 |
| 撞击体＋护盾体 | 先处理层盾，再处理护甲；选择穿层工具 |
| 行军体＋护盾体 | 大量低值盾消耗低频范围事件 |
| 前排＋攻城体 | 正面承压与后排持续拆设施 |
| 前排＋曲射体 | 高地、安全死角和维修区的风险 |
| 突进体＋鼓舞体 | 保留近线持续火力与应急窗口 |

同样预算不代表同样威胁。军团验证应比较相同单位有无协同、相同数量不同任务等情况，而不是仅比较总生命。

## 7.5 污染普通敌人

污染来自浸染、环境或特殊场景。携带者的近战和远战命中可以附着设施污染，来源强度与兵种攻击节奏分别调节。

视觉保留原轮廓，同时改变同步、曲率、重复节点和运动相位。玩家应首先识别它是撞击体还是攻城体，然后看出它携带污染。

献祭污染普通敌人可获得较高Q。神秘祛除塔可降低其污染、提高针对性斩杀和祛除伤害。敌方去污没有资源回收。污染状态不修改普通／异常身份标签。

## 7.6 异常指挥团

异常指挥团无地图实体，负责全场数量、种类比例、同类并存、投放窗口、补位和高影响施法排程。异常不随每支普通军团模板重复生成。

异常单位本身高生命、具备自保，通常避免正面冲锋。其作用范围大但有限，需要到具体战线寻找窗口；施法后尝试回撤。安全位置和路径不应使工业路线永远无法触及它。

异常单位可独立于某波普通敌人继续活动，受到关卡昼夜与清场规则统一管理。击杀获得实质喘息时间，不立即同位补出满准备单位。

## 7.7 十一种异常单位

| 名称 | 主要能力 | 符号与战术身份 |
| --- | --- | --- |
| 盲目 | 观察与瞄准干扰 | 眼睛；侵入精确信息能力 |
| 迷乱 | 动作降频 | 错位旋纹；侵入工程操作能力 |
| 缄默 | 吟诵中断 | 嘴与封口；侵入神秘组织能力 |
| 狂热 | 激进进攻和对控制的行为响应变化 | 向外展开的放射构型 |
| 庇佑 | 异常比例减伤 | 层叠包围结构 |
| 桎梏 | 单次伤害上限 | 钳制、截断框 |
| 间歇 | 有效受伤频率约束 | 有节律空窗的分段环 |
| 复归 | 远距离高强度恢复 | 回卷、重组的结构 |
| 否认 | 短时间免疫一类明确效果 | 闭合的空白边界 |
| 门扉 | 近线输送、召唤与空间锚定 | 嵌套门框、开口 |
| 浸染 | 向战区抛射污染物 | 生化危害式三瓣母题 |

### 盲目

普通施法干扰有限区域内依赖弹道解算的塔，攻击仍然真实发生，但落点失准；误打可能命中其他敌人。注视类失去持续观察，法阵的已定区域和构型不依靠同一瞄准关系。

元施法前眼睛观察战场之外，再合眼，使UI精确数值层一同闭合。战场可见、命令仍可下达，玩家依靠结构破损、能量节律和状态符号判断局势。

### 迷乱

普通施法使范围内一般攻击设施数秒内动作降频，而非把所有工业功能同时关掉。生产、电网和其他能力是否受影响取决于明确标签，默认只针对攻击动作。

元施法让卡牌及出售、升级、改建按钮变成眩晕符号，短暂拒绝工程命令。既有防线仍自动作战。暂停、相机、音量、设置和退出保持可用。

### 缄默

普通施法作用于诵经阁、读阵、咒杀等吟诵概念。注视和普通炮火继续。诵经进度暂停保留；咒杀持续关系被切断后按自身规则重新累计；已经形成的独立区域继续其存续时间。

元施法冻结全局仪式准备推进和神秘部署能力。已就绪资格保留，玩家此时不能放置；已有终结型仪式继续生命过程，维持型召唤按其实体规则活动。

嘴形闭合实际改变BGM的吟诵声部，但保留关键战斗预警和软件声音控制。

### 狂热

向选定部队施加激进战斗状态：更积极冲锋，提高相应攻击节奏，减少麻痹后主动减速整队的倾向。方向扰动仍然存在，狂热不等于无条件控制免疫。

它改变较大尺度的战斗响应，可随异常指挥支持不同战线，区别于鼓舞体身边的普通节拍增益。

### 庇佑

给选定敌群维持比例减伤。它不是层盾，也不随目标数量无限复制总保护能力。作用范围、覆盖数量、持续时间和补施节奏共同约束压力。

### 桎梏

限制目标一次本体伤害的上限，抑制低频高伤。单次的定义与伤害包一致，重炮独立爆炸、持续小额伤害各自结算。持续时间和施术者提供可利用窗口。

### 间歇

限制一定时间内的有效伤害频率。默认以目标共享受击窗口处理，避免多座塔简单绕过。对高频武器有明显压力，低频重击仍有价值。

它与桎梏同时作用会显著压低所有常规手段，指挥团必须按组合压力评估，保持可突破的持续时间和输出窗口。

### 复归

对远处的指定高价值部队进行强恢复，需要可见施法与有限工作预算。起步只恢复生命，不同时复活、补甲和补盾。普通修复体是局部维持，复归是更高范围和关系权限的恢复。

### 否认

短时间否认一类明确效果。标准原型先采用新控制／负面状态的暂时免疫；伤害免疫属于后续独立变体，需专门预警与验收。

免疫类别、剩余窗口和结束可被识别，不以“异常单位天生魔法抗性”替代规则说明。

### 门扉

通过可见锚点在防线近处输送或生成有限敌军。施法者、锚点、读条和可落地空间共同提供反制条件。传送可以使用重度污染设施作为媒介，但这属于局部C达到高危阶段后的已预告能力。

投送不凭空跨过所有空间合法性，不能无条件把不可处理军团塞进核心。投送人数、质量和补位受指挥预算管理。

### 浸染

向攻击范围内抛射污染物。命中普通敌人，赋予近战与远战附着污染；命中玩家设施，直接增加局部C。同一次动作完成军团强化和设施侵入。

它偏好敌我接战密集区、即将接敌的部队或关键设施群。主要威胁来自后续污染与维护挤占，直接生命杀伤保持次要。附着刷新或按明确强度覆盖，不无限叠加。

## 7.8 P3—P5能力权限

危险元交互异常从P3起出现。等级主要影响投放、范围和施法权限，身体耐久不按P机械翻倍。

| 档位 | 日常施法 | 元施法轮次 |
| --- | --- | --- |
| P3 | 大而有限的局部范围 | 较少出现，替换一次普通作用 |
| P4 | 局部范围扩大 | 替换频率提高 |
| P5 | 日常仍为有限局部范围 | 元效果与一次全场普通作用同步 |

P3、P4的替换轮次不同时追加普通打击。P5只有特殊轮次全场化，之后回到普通接近—施法—后撤。元轮次仍必须获得真实战线施法机会，不能在出生点空放技能积累。

施法周期固定、可学习，逐次增加符号预兆。被打断不凭空记为完成一次正常施法。世界升级不临时扩大已经预告的技能。

## 7.9 并发与交互底线

指挥团同时管理在场单位与技能重叠。盲目、迷乱、缄默属于直接剥夺玩家信息或命令的高影响类；狂热、庇佑、桎梏、间歇、复归、否认属于战斗强化；门扉和浸染属于结构干涉。

盲目＋狂热＋间歇可以形成强压力。盲目＋迷乱＋缄默的高阶窗口在普通关卡不形成长期连续锁。完成一次强干扰后保留可操作的恢复间隔，规则由调度层执行，不靠随机希望它们错开。

挑战关可以公开调整并发约束。最高难度仍保留软件控制、可归因预告和明确持续时间。

## 7.10 敌人状态与画面

每个单位首先凭外轮廓和功能构件识别兵种，再凭外层结构识别护甲、层盾、污染和异常状态。层盾以薄环、弧片或节点层逐次减少，护甲以承力板破损表达。

普通动作有功能原因，污染改变同步与关系，异常让符号直接成为器官。优先展示生命危险、技能预兆和关键支援，装饰不得掩盖军团边界与炮击落点。

敌军美术规格详见《美术、界面与声音》。所有效果都需要在密集战斗、低缩放和数值层被盲目遮蔽时仍可辨认。
