## 4.1 内容范围与成长

工业名称采用简洁的功能和器械称呼。本章包含标准常驻设施、护盾成长分支和四种道路消耗物。所有具体价格、攻击周期、范围及能源参数在数值配置中维护。

常规设施从V0起步，核心科技开放后续强化。大型融合以最终满级材料构成，新实体为V0；维持原有投资和生命比例，新的攻击能力等待自己的完整首次周期。

## 4.2 核心与基础设施

| 名称 | 职责 | 关键约束 |
| --- | --- | --- |
| 核心 | 胜负、基础收入、基础发电、无线覆盖、科技中心 | 不生产神秘值；外围生产仍有扩张价值 |
| 金矿 | 在矿点周期生产金币 | 受工作状态和供能影响，离散收入首次需等待周期 |
| 发电机 | 稳定持续产能 | 需要接入覆盖，不自带无限输电 |
| 太阳能板 | 天气和昼夜相关的产能 | 晴昼强、阴昼一般、晴夜低、阴夜与雷雨停摆 |
| 蓄电池 | 储能和短时供给 | 能量容量与充放电功率独立；可承接雷击脉冲 |
| 供电塔 | 本地覆盖与跨区转供 | 本地交换不限远程流量，向外总转供有限；天然引雷 |
| 稳定锚 | 高耗电压制环境污染 | 按有效稳定规格匹配世界污染，重叠取最强 |
| 稳定中继塔 | 供电塔与稳定锚集成 | 任一方向可补装；完整成本高于两座同规格独立设施之和 |
| 支撑墩 | 炮位承载与人工后靠 | 结构高度随等级增加，不改变真实射界高度 |
| 维修塔 | 修复生命与局部污染 | 两者共享有限工作预算；合格稳定环境提高污染修复效率 |
| 围墙 | 被动阻挡、承伤 | 是常规防线的时间与空间工具 |
| 护盾 | 基础防御载体，V2后选择终端防护方式 | 电能护盾与拒止立场属于同一设施的V3分支 |

稳定中继保留引雷属性。把供电和现实稳定压在同一格会节省空间，也集中战损风险。玩家仍可选择分开的节点与稳定锚。

## 4.3 护盾的V3分支

护盾V0—V2提供基础防护，具体容量、体积和恢复方式随等级配置。其V3成长分为电能护盾与拒止立场，二者不是另占卡槽的独立塔。

### 电能护盾

以电力维持并恢复容量式保护。匹配防护条件的伤害先由护盾承担，容量足够时本体获得完整保护。容量耗尽后本体继续承受后续伤害。

恢复速度、重启条件和电力需求是主要平衡量。玩家护盾与敌方多层次数盾是两种机制，使用不同外观和状态提示。

### 拒止立场

持续消耗神秘资源，建立区域性的空间阻滞。小体型敌人与平射实体弹丸在区域内几乎寸步难行，大型敌人仍能缓慢强行推进。

对于抛射、自爆和死亡范围爆炸，立场向受保护设施提供有限减伤。它既不取消这些事件，也不把所有威胁转成静止目标。弹丸寿命照常消耗；能否最终抵达取决于剩余寿命和运动距离。

敌人和弹丸离开区域即恢复普通运动。相同立场以最强效果作用，叠放扩展覆盖与冗余。立场不直接提供伤害，积累的敌群需要其他输出处理。失去维持时，滞留敌群恢复推进。

该分支需要神秘权限；具体M档位在解锁表验证，当前以M2作为闭环默认。T决定护盾能够达到V3，M决定该神秘方向可用。

## 4.4 机炮

基础连续单体火力。实体弹丸、清楚的发射方向和稳定射击周期形成工业输出基准。适合处理零散敌人、突破单位及连续剥层。

机炮对重甲磨损较弱，范围吞吐依靠多座覆盖。四座满级机炮是巨炮的核心材料。机炮的长期性价比和部署灵活性应贯穿整个游戏。

## 4.5 火炮

火炮必须安装在支撑墩上。它是常规平射范围火力，发射实体弹头，到达落点后展开主爆炸与少量次级爆炸。

升级增加弹片数量，事件在较小空间与短时间内重叠。每个爆炸都是对全体合法目标生效的真范围伤害。面对多层薄盾，有限事件数仍有明显不足。

火炮使用固定单发能量，缺能时延后射击。它的优势来自密集目标的单位资源收益，代价来自落点、弹道、射界与空窗。

## 4.6 迫击炮

同样安装在支撑墩上。抛射轨迹越过普通地形，利用山后、凹角和安全位置建立火力。弹头飞行时间和目标运动造成真实的命中风险。

它可以拥有可观的单发伤害，而不必用低伤害抵消安全炮位。低利用率、近距离压力和对快速目标的预测成本构成其主要限制。升级增加少量次级爆炸。

## 4.7 狙击塔

长射程、低频、高单发的专业点杀与破甲工具。伤害绕过护甲减伤，并一次削减大量护甲；普通层盾按连续总量处理，可一发拆多层。

射线受真实地形限制，小型敌人具有明确、可调的遮挡概率。向低处射击时遮挡减弱。被遮挡的攻击有实际命中或耗散结果，不凭空绕过所有掩护。

狙击为后续工业火力打开目标，清理杂兵的效率较低。它与咒杀的区别在于立即打击及破甲协同。

## 4.8 电塔

固定周期释放上一个充能阶段实际获得的能量。最大普通汲取速率很高，常规防线中通常无法一直吃满；单发威力因此浮动，机械节拍保持稳定。

攻击从单体开始，击杀后的未消耗预算在附近敌人间继续传导，不设逐跳衰减和固定跳数。电塔处理普通层盾时可以穿层，但仍支付护盾和减伤消耗。

高质量本地供电、电池和雷击提高其可兑现威力。电塔的收益是可靠命中和过量伤害利用，代价是电力竞争、较近作用距离及充能历史。攻击可以附带短时麻痹，实际效果与该次放电的能量相匹配。

## 4.9 静电塔

近距离持续覆盖所有合法敌人，按敌人数提出线性功率需求。伤害与麻痹强度随实际供能比例共同变化。它不依赖普通环境视线，因此不吃天气射界修正。

大量敌人、补员和分裂会扩大负载，拖慢同区其他消费者。高强度本地供电可以把这种负载转成真正的持续清场。静电穿层伤害使其对薄层盾群有价值。

## 4.10 电磁炮

高科技快速单体实体炮，采用高弹速和高攻击频率。它是后期高耗能、稳定单体吞吐工具，不承担狙击的大额破甲职责，也不使用电塔的蓄能溢出连锁。

层盾主要靠高频攻击逐层处理。高科技门槛和持续供能成本保证它与廉价机炮形成不同投资选择。

## 4.11 巨炮

配方为2×2四座满级机炮及追加建设成本，融合为巨炮V0。背侧两格需要足够的天然或人工后靠；朝向改变时重新验证。

发射有限寿命的大型直射弹，沿轨迹穿透不同敌人，同一弹体对每个敌人只结算一次。巨炮有明显射击扇区、高单发能量和较长空窗。

它利用纵深队列和方向性炮位。地形阻挡、横向散开和普通层盾削弱收益。生命、碰撞与出售均按一个四格实体处理。

## 4.12 重炮

四座满级火炮在2×2区域内连同既有基础融合为重炮V0。基础已经构成大型炮的工程部分，后续升级不重复放墩。

重炮生成密集但略有时空错开的爆炸事件簇，制造真范围伤害和显著麻痹。其特长是打乱军团推进并连续敲击多层盾。

同一发多个麻痹事件遵守统一强度与刷新规则，不能无限叠加方向扰动。大量事件提高实际覆盖，也提高供能、落点规划和输出节拍的重要性。

## 4.13 岸炮

2×2区域中两座满级火炮、两座满级迫击炮及其基础融合为岸炮V0。配方可以旋转，材料布置在预览中明确。

岸炮射击慢、射界极远、单发高伤，弹片丰富，空间和时间分布比重炮更展开。一次射击形成短时炮击覆盖。

它主要提供远距离投送和宽区杀伤，重炮主要提供密集冲击与麻痹。岸炮的抛射越障与观察需求分别定义，雷雨仍可能降低获敌距离。

## 4.14 工业道路部署物

四种炸弹低建设成本、长卡牌冷却，提供有限次数的应急能力。可放在指定可行走道路，通常不阻挡敌人。除地雷外稳定自耗生命，血量同时表达引信进程。

所有炸弹在战斗内生命归零时爆炸，来源无关；不可维修或接受回血，也不可出售回收。不同类型分别有一份冷却，卡槽构成同时携带多个应急工具的代价。冷却只随模拟时间推进，不在阶段换卡时重置。

| 名称 | 核心效果 | 使用场景 |
| --- | --- | --- |
| 炸弹 | 中等范围与伤害的标准爆炸 | 临时弥补范围火力和突破缺口 |
| 震荡弹 | 降低伤害，扩大范围并施加强麻痹 | 给防线争取重新组织的时间 |
| 破片炸弹 | 更小作用范围、更高集中伤害 | 处理局部高质量密集目标 |
| 地雷 | 一格量级的高伤害；无自然自损，敌人进入触发区后归零引爆 | 预埋在可判断的必经位置 |

“破片炸弹”的名称表示集中的碎片杀伤，具体独立伤害段数另行配置，不能仅凭名字继承重炮全部事件簇强度。炸弹仍经过层盾、护甲和异常防护结算。

雷击、敌军攻击和明确可伤害部署物的效果都可使炸弹提前爆炸。普通伤害的阵营过滤保持明确，污染导致的友伤另有预告。

## 4.15 视觉职责

机炮表现连续机械节奏；火炮和迫击炮表现一发内部的少量爆炸；重炮和岸炮表现时空展开的炮击；巨炮表现方向性贯穿；电塔表现有限能量的一次传导；静电表现持续场。

基础结构包括基座、转轴、功能构件、能源接口和状态节点。升级增加可辨认的结构或事件层级，同时保持常用缩放下的清晰轮廓。
