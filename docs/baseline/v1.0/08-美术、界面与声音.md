## 8.1 主风格

美术以二维构成主义组织画面，以功能主义解释结构。整体典雅、柔和、细腻、符号化，保持清楚的战场关系与充足留白。

简洁不是把每座塔压缩成最少线条，而是让主次构件有意义。基座、转轴、承力件、发射机构、供能口和维修节点共同形成可读机器；圆角、线宽层级与少量半透明填充让结构具有柔和过渡。

工业和神秘共享同一套材料语言。区别在于构件如何组织、如何运动，以及结构与功能之间是否仍然具有可靠因果。

## 8.2 构件化视觉语法

每种标准实体保留主轮廓、主功能构件、少量活动构件和独立状态层。常见图元包括线段、弧、圆、板件、节点、框、短连接和分层轮廓。

线宽保持少量档位，主轮廓优先于内部细节。光照与渐变只用于辨认层次，不用发光强度掩盖形状。色彩优先表达资源、阵营、危险和当前操作，形状承担主要类别识别。

地图、实体、攻击、状态、选中和预警各有层级。关键功能反馈始终高于装饰。远景简化内部构件，近景展示更多结构，实际战斗身份和碰撞不随细节层级改变。

## 8.3 工业设施的构成

机炮表现中轴和连续出手，火炮表现炮座与回冲，迫击炮表现上抬与配重，大型炮表现集成基础与分层机械。电塔体现电容储能、固定节拍和一次放电，静电体现持续负载与近区作用。

支撑墩有清楚的承力形态，但视觉不能让玩家误以为它是改变射界的山。炮位装配后仍可看出基础。护盾V3的两个方向保留同一个基础轮廓，分别增加能源防护和空间拒止结构。

升级增加功能结构成熟度、状态节点或爆炸事件层次，而不是统一用更多亮光表示高级。四格融合的外围轮廓明确属于一个实体。

## 8.4 神秘视觉参考的分工

| 参考源头 | 本作使用的语义 | 主要载体 |
| --- | --- | --- |
| 宇宙恐怖 | 被注视、未知秩序、人的尺度被越过 | 高污染UI、观测、元交互 |
| 非欧几里得超现实主义 | 矛盾连接、偏心中心、不可能闭合 | 法阵、关系线、异常空间 |
| 生物机械 | 机器结构像器官一样工作 | 神秘工业、污染过渡、异常实体 |
| 肉体恐怖 | 不合时宜的柔软、收缩和搏动 | 少量高危局部构件 |
| 赛博符咒 | 工业电子结构承载仪轨 | 转经轮、诵经阁、经书界面 |
| 新图腾主义 | 简明的家族母符号 | 仪式家族和异常类别 |
| 警示图形学 | 立即可识别的危险类型和阶段 | 施法预告、污染风险、状态 |
| 重工业恐怖 | 大尺度遗产、沉重的机器秩序 | 旧工业地图和大型装置 |

这些是不同视觉问题的参考来源，不要求每个对象同时混入全部元素。“非欧”在美术中表达不安的几何关系，不构成对实际地图拓扑的实现要求。

玩家神秘侧可以直接使用传统宗教器物与仪式符号，其命名清楚、正常。异常侧和失控过程承担更强的不安。使用具体符号时记录来源和自制过程，虚构组合保持自身的一致语法。

## 8.5 正常、神秘工业与污染的连续关系

正常机器的结构能解释功能。神秘工业仍然有可识别的工程组织：机器在读经、转轮、刻阵。污染则让原本必要的功能节点出现多余连接和新的运动理由。

轻度：相位微差、曲率变化、节点轻微偏心。

中度：辅助连接重排、局部重复增加、转轴带出眼状或环状意味。

重度：原有形体仍可辨认，但内部结构开始像另一个系统借机器活动。

这些状态通过可复用参数连续生成。进入高污染不等于换一张毫无关系的新贴图。玩家必须始终识别它原本是维修塔、炮塔还是电网节点。

## 8.6 普通敌人和异常敌人

普通构造体名字描述职责，轮廓与功能一致。行军体规则活动，撞击体前部压缩回冲，攻城体架起炮架，护盾体转移薄环，补员体开合装配腔。

污染构造体保留兵种轮廓，改变同步、曲率、节点和闭合，攻击逐渐携带异常附着。异常单位则使眼、嘴、门、三瓣危险形直接成为功能器官。

运动的是构件与构件关系，而非人物步行、挥手式动画。普通移动有稳定节律，施法有构型变化，受伤有结构缺损，恢复重新接合。相机缩小时仍能读出主要职责。

## 8.7 各攻击家族的视觉因果

| 家族 | 因果语言 |
| --- | --- |
| 机炮、狙击、电磁炮 | 出手、轨迹、明确命中 |
| 巨炮 | 一枚具有方向与寿命的重弹贯穿 |
| 火炮、迫击炮 | 一发落点内部的少量爆炸 |
| 重炮、岸炮 | 时空展开的多次爆炸，共同形成区域杀伤 |
| 电塔 | 储量可见，按固定节拍释放有限预算并溢出传导 |
| 静电 | 区域持续工作，亮度或节律反映实际供能比例 |
| 分解 | 预兆区域成立，目标结构受检验，死亡后解体 |
| 吸魂 | 延迟后从真实受击者抽离细线或物质 |
| 触手 | 土地活化，构件间歇出现与收回 |
| 注视、咒杀 | 对象间关系建立，标记逐渐变化 |
| 仪式 | 经书准备、实体落地、生命过程与结果 |

范围边界只在预览、选中和危险时强调。每个命中有可复查状态，视觉可合并，实际受击集合完整。神秘攻击不要求都画同心圆，也不需要粒子爆炸统一其身份。

## 8.8 世界污染的界面侵入

P0以有层次的直线、柔和圆角、模块化布局和功能节点为主。P1—P3逐渐把圆弧、环、眼状结构和重复纹路融入界面。P4—P5进一步改变装饰关系、构件相位和边界组织。

界面骨架、文字位置和命令热区保持稳定。正常污染装饰不移动按钮、不伪造余额、不使预警不可读。不可逆的世界P决定整体侵入程度，花掉Q不会突然恢复低污染皮肤。

M权限、P环境和Q库存同时可查。M3之后，下一条阈值明确标成世界污染提升，避免把P4、P5误读为新科技奖励。

## 8.9 真实界面攻击

盲目元攻击使已有眼纹合眼，精确数字和对应数值面板暂时不可读，战场本身保持真实；不要一边隐藏数字一边保留能准确替代全部数字的同等信息面板。

迷乱元攻击使建设卡与工程按钮出现短暂眩晕构型，命令反馈明确说明当前不可执行。缄默元攻击封住神秘相关准备与部署，同时用闭口构件和声部缺失传达。

三类攻击都有施法源、预告、持续时间和恢复。交互锁定不影响暂停、相机、设置、退出和辅助选项。恢复时回到原有界面布局，不把期间点击排队为恢复后的意外建造。

## 8.10 局部净化向UI转移

净化塔抽离设施异常时，构件或符号先从塔体分离，经设备收束，再以克制的屏幕空间动势汇入神秘值区域。塔更整齐，UI吸收更多异常结构。

接近阈值时，汇入图形可以逐渐补全一个新的构型；突破时该构型成为下一档界面的一部分。动画只反映真实入账和等级，不能因装饰延迟错过预警。

神秘祛除敌人时使用拆解或解扣效果，不把被去除的敌方污染飞入资源UI，因为该行为没有Q回收。

## 8.11 音乐与音效

BGM采用分层组织，基础工业节律持续存在，污染增加低频、持续音、错位重复、诵唱或其他异常声部。变化跟随P而非瞬间Q余额。

玩家侧诵经是稳定工业活动，敌方异常声部强调不合时宜的关系。高污染可以打乱装饰节律，但关键节拍、技能预告和伤害反馈仍有清楚的听觉层级。

缄默改变BGM与吟诵声部，不关闭全部声音。盲目时保留合理声源帮助玩家读战场，声音不提供隐藏精确数字的完整替代。雷击先有预兆，再有明确冲击与网络脉冲反馈。

提供降低闪烁、构件抖动和高强度声效的选项。辅助选项调整表现强度，不改变技能持续时间或战斗效果。

## 8.12 程序化素材管线

素材主要由代码、矢量和参数化几何生成。静态构件可离线生成图集；运行时驱动状态变形、旋转、闭合、局部相位和少量特效。统一保存可编辑源、参数、导出设置和来源记录。

绘制代码可以由AI辅助，但进入项目的资产应当可复现、可审查和可批量修改。使用者需要知道图形的功能目的、图元边界和状态映射。

规则层只提供身份、位置和状态，表现层消费结果。图案上的装饰节点不是额外敌人，构件摆动不直接改变碰撞体，渲染简化不改变游戏规则。

## 8.13 美术验收

同一场景至少检查正常缩放、最小常用缩放、密集交战、选中建造、局部污染渐变和高P界面。需要辨认兵种、塔功能、护盾层、护甲、污染、蓄能、缺电与技能预告。

动画检查直行、转弯、停止、接敌、施法、死亡和恢复，确保构件有功能意义且不高频抖动。数值被盲目遮蔽时，玩家仍应能判断防线哪处正在失效。

来客塔可以违背标准美术语言，但属于明确扩展，不反向改变普通资产规范。
