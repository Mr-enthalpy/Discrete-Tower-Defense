## 1.1 核心与科技

核心同时承担胜负目标、保底金币生产、基础发电、基础无线覆盖和科技入口。它不生产神秘值。核心的基础供给保证开局能够启动工业和最低限度神秘生产。

科技从 T0 开始，升级核心依次到 T3。升级通过金币及明确的工程条件支付，解锁新设施，并提高常规设施允许达到的最高 V 级。默认使用 V 上限随 T 同步开放的关系；终端设施、消耗物和仪式采用自己的成长规则。

核心成长应让既有基础设施继续有投资价值。四座满级基础塔指内容定义的最终 V3，不把“当前科技能达到的最高级”视为最终满级。融合形成的新设施为 V0，原设施实际投入转入新设施账目。

工业常规科技的具体解锁表属于平衡配置。内容定位为：T0启动与自保，T1成型生产和基础炮兵，T2专业火力与维护，T3大型融合与高技术武器。电磁炮处于高科技端；大型融合需要满足满级材料的科技前提。

## 1.2 神秘权限与世界污染

神秘值 Q 是当前库存。设五个递增库存阈值，前三级同时推进神秘权限与世界污染，后两级继续推进世界污染。M最高为3，P最高为5。普通发展中，突破自动发生，已获得的权限与已发生的污染在本关保留。

关卡可以分别设置初始 M、初始 P、初始 Q 与背景泄露。已有的高污染环境不自动证明玩家已经掌握相应仪式，因此可以出现 P5、M0 的旧工业残局；神秘遗产关则可以同时给予较高 M 和现成设施。

Q 入账时立即检查跨越阈值；一次收入跨越多级时，所有对应等级生效。后续消费降低库存，不回退历史等级。低库存的高吞吐运行可以延缓下一次库存突破，属于公开的运营策略。

污染状态、美术和敌人权限使用同一等级记录。跨级立即改变世界状态和后续投放权限；新高阶敌人从有预告的生成窗口进入。场内异常的能力升级在当前技能结束后的下一轮生效，已经开始的预告保留原范围与强度。

## 1.3 单局循环

标准关卡采用“备战—白天—黄昏—夜晚—黎明”的循环。备战可规划开局；白天负责生产扩展；黄昏提供下一阶段情报；夜晚承担主要攻势。具体长度、总天数和阶段差异由关卡配置。

标准黎明结束前夜生成，清理敌军和飞行中的战斗效果，恢复可复苏的永久设施。生命归零的普通设施保留残骸占位，停止工作和阻挡；黎明复苏后恢复其既有身份。局部污染与塔的累计历史独立于生命恢复，按各自规则保留。

黎明不凭空补充电池、电塔储能或神秘值。一次性炸弹、已消耗仪式和离场召唤物不复苏。夜末同一步先结算战斗及核心死亡，再判断黎明和胜利。

特殊关卡可以改变循环和复苏规则，但在关前作为客观环境条目公开。

## 1.4 三种路线

纯工业、纯神秘和混合描述战斗与异常处理的主体，不排斥共享核心、金币和基础电网。

常规敌军关通常以纯工业运营压力最低，混合需要额外基础设施和卡槽，纯神秘需要组织仪式和条件输出。在异常压力显著的长期战斗中，混合体系通常最宽容；纯神秘需要处理普通兵潮，纯工业需要更高水平的阵地、点杀、稳定和维修。

最高污染下，纯工业必须有可验证通关路径。神秘能够缓解一些问题，但每一种必要异常威胁都应有正常火力、空间、时间或工程维护的应对窗口。

路线难度由地图问题决定。常规敌人也可以通过高质量、经济与地形组合使神秘介入更划算。已有工业足以改造应对的关卡，仓促建设神秘工业会浪费窗口。神秘遗产关可以先用现成仪式处理少量精英，再随普通兵潮增长补上工业吞吐量。

## 1.5 关卡原型

| 原型 | 开局条件与主要问题 |
| --- | --- |
| 经营型 | 资源紧，近期压力可判断；投资生产意味着承担近期防御风险 |
| 防御组织型 | 经济较宽裕，战斗强；重点是火力分工、电网和阵地可靠性 |
| 综合扩展型 | 前期建设经济，后期扩大战线并转向持续高负载防御 |
| 旧工业遗产 | 大量旧设施、高污染与泄露，异常投放加快；争取转型窗口 |
| 神秘遗产 | 现成神秘资产、先少量高质量敌人，之后加入持续普通军团 |
| 特殊挑战 | 明确改变常规约束，例如异常元效果组合、特殊补给或恶劣天气 |

地图扩展同时开放机会和责任：矿区、炮位、可用平台与新的进攻面共同增加。长关可以改变昼夜长度，使此前足够的储能或生产方式需要重新组织。

## 1.6 关前情报

关前公开地图全貌、扩展顺序、入口与核心、矿点、地形高度、道路和建设区、初始设施与状态、昼夜节律、总天数、天气规则、初始 M/P/Q、背景泄露、可能敌人种类及换卡节点。

情报陈述事实，不提供关卡解法或路线评分。随机天气、条件异常池和特殊规则应标明其变化条件。是否因玩家提高污染而扩展敌人池也属于预览内容。

黄昏提供下一阶段的方向和威胁类型，精确单位顺序由关卡决定。敌方技能本身另有场内预告，战略情报不能代替实际施法提示。

## 1.7 卡槽与阶段转型

卡槽限制可建设的内容选择。基础设施、武器、炸弹和具体仪式成员按关卡编成规则占槽；V级强化和护盾的V3方向是既有设施成长，不重复占独立塔卡。

短关保留开局编成。长关在公开的结构性节点提供重选窗口，例如扩图或显著昼夜变化。节点可配置允许替换的槽数，并在预览公开；这不是每个昼夜自动提供的临时换装菜单。

换卡后，已有设施保持生命、供能、攻击、维修、转向和既有等级。默认允许继续强化既有同类设施；新建和融合到另一内容检查当前卡组的输出权限。实际投入和成熟资产因此具有长期价值。

仪式成员决定诵经阁可选择的家族典籍。某族全部成员离开卡组，该族诵经阁回归中性；现有阁保留，后续可换读合法典籍。家族准备进度暂停保留，但没有合法成员时不可部署，也不继续生产。重新带回该族不复制进度或就绪份数。

## 1.8 玩家操作

支持选择、检查、建造、强化、融合、出售、暂停、变速和重开。暂停中合法建设仍检查费用、空间和部署冷却，所有模拟时间停止。变速通过推进同样的模拟步实现，保持规则含义。

普通设施出售按实际投入和公开折损规则返还。融合材料的投入只转移一次。炸弹和仪式一经落地进入其一次性生命周期，不提供回收退款。

战场命令被异常锁定时明确反馈原因；锁定期间的失败点击不在恢复后自动执行。终局仅保留查看、结果回顾、重开和退出。
