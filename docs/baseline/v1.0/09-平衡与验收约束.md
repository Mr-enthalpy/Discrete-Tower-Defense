## 9.1 平衡目标

平衡首先验证风格化的有趣、可解释的失败和合理难度曲线。每个系统应当有清楚职责，每次扩张应当增加可判断的取舍。

本章给出关系和场景，不规定最终塔价、伤害表或算法。记录的预算和样例都是试验起点，性能和胜率必须由实际测试得出。

## 9.2 经济与关卡压力

经营关需要验证提前投资经济确实牺牲近期防守，不能让无风险早期回本同时带来更高现金和更多永久产能。防御组织关允许经济宽裕，压力转向阵地、能源、吞吐与维护。

长关前后半段应有问题转换，既有资产有持续价值，转型又有真实成本。免费黎明修复、核心收入、矿点、暂停建设和出售折损都要进入经济评估。

比较先生产、先防守和先科技时，检查有效收入、受损停产、施工窗口与实际通关，而不仅比较静态回本秒数。

## 9.3 路线约束

常规敌军场景通常由工业提供最经济的持续解法。异常场景中混合路线通常更宽容，纯工业需要更高运营，纯神秘需要更仔细地组织非平滑输出。特定地图可以反转这个顺序。

最高P标准关必须存在实际可玩的纯工业方案。该方案可以昂贵、狭窄、节奏要求高，但不能依赖理论上永远无法到达的异常单位、不可获得的锚规格或隐藏的指定仪式。

纯神秘具有M0自保链、阶段控制、持续削盾和终结工具。允许高手用大量诵经阁和仪式完成一般波次，成熟规模的收益必须真实。来客玩法不进入标准路线保证。

## 9.4 每座塔按完整成本衡量

完整成本包括金币、科技、前置满级材料、基础占地、支撑、供电、储能、维修、神秘准备和卡槽机会。组合后的V0不必全面优于材料阵列，但应在其专长场景有可感知收益。

升级增加弹片意味着更多事件、层盾互动和时空覆盖，不能只按面板总伤害调节。扩大范围也增加实际命中机会和电场需求。控制改变敌群空间关系，可能使穿透或爆炸集中度下降。

万魂幡的小幅线性本底成长要在实际关长与可获得击杀中检验，避免很快抹平吸魂的收尾短板。长期成长可以强，但不应使其同时变成低成本万能破盾工具。

## 9.5 电力和雷雨约束

静电塔N倍目标带来N倍满强度请求，供能不足均匀降效。电塔固定周期内的实际能量决定威力，普通充能不能在最后一瞬无视汲取上限补齐全周期亏空。

雷击提供有限总能量，本地交换畅通不等于每个消费者无限接收。测试必须同时包含少量裸电塔、节点加维修、加电池后的成熟阵地，以及远程限流的对照。

雷雨电系可以明显释放上限，但射界收缩、太阳能停摆和节点伤害同样真实。不能只记录雷击后的峰值伤害，而忽略战损和未利用能量。

## 9.6 护盾、护甲与伤害规则

| 对照 | 需要观察的结果 |
| --- | --- |
| 无盾敌群与多层薄盾敌群 | 一般重击浪费溢出，高频和穿层具有不同优势 |
| 重甲与无甲 | 狙击改善后续全防线输出，咒杀只解决自身关系 |
| 同样总伤害的单包与多包 | 多包只有实际命中时才逐层贡献，炮击时空分布可影响效果 |
| 健康与残血目标 | 吸魂与分解处于不同效率区间 |
| 污染与已洗净目标 | 祛除加成、污染削除和献祭回收发生正确变化 |
| 异常防护组合 | 至少保留可击杀、可等待或可打断的工业响应窗口 |

“固定数量”与“真范围”属于不同动作。献祭和吞噬有明确名额，爆炸和区域持续伤害对所有合法目标结算。普通层盾不会被神秘视觉直接越过，只有已经声明的穿层或绕盾能力例外。

## 9.7 控制与拥堵

麻痹需要让玩家看见推进质量变化，而不是数值减速的换名。未接战和已接战响应分别验证。多次爆炸不得把扰动叠到无法辨认或穿墙。

拒止和触手可以制造高密度区，也会积累失效后的风险。不能依赖无限刚体挤压、卡死和无法重新获得路径来制造防御强度。

冻结、回传和触手仪式可很强，但长期连续控制仍需通过准备吞吐、空间、持续时间和异常免疫窗口检验。结束后的敌人恢复正确任务。

## 9.8 维护与资源回路

测试无锚维修堆叠在低P可行、高P不能长期自稳；合格高阶锚与干净维修在高P下应有显著恢复能力。主动污染仍能制造工作负担。

净化、献祭和被污染设备可以回收Q。实际收益进入阈值检查，重复来源不能复制。P已封顶的情况下仍需验证回路是否使维护、火力与敌方压力全部失去意义。

临时路障、小炮和可保存仪式允许回血维持。若长期维护成本低到全面替代永久工业，应调整运行和生命预算，而非取消“回血挽留”这一机制。

## 9.9 异常单位与元交互

危险异常要有真实接近和暴露窗口。高生命不等于无限追杀成本，施法后撤也不能让所有常规火力永远无法作用。技能打断与击杀必须带来可感知喘息。

P3、P4检查替换关系，P5检查仅特殊轮次全场化。范围和强度在预告后锁定。重复交互干扰有恢复间隔，数量限制与技能排程共同成立。

盲目期间有信息不完整的行动空间；迷乱期间能看见既有防线运行；缄默期间工业和不依赖吟诵的作用仍有价值。普通关不长时间叠成“既不能看、又不能下任何命令”。

## 9.11 观测指标

按问题记录少量可解释指标：资金与投入时间、核心最低生命、每种武器的有效伤害和过量损失、实际范围命中、层盾消耗、破甲、有效治疗、污染修复工作、Q来源与阈值时刻。

电网记录产能、需求、实得、瓶颈、脉冲利用和电池轨迹；军团记录补员、支援存活、突破与任务；异常记录施法、打断、元干扰时长和空窗。

性能可从人工的数百设施、上千敌人场景开始探测，但它只是工程压力夹具，不是每关必须达到的敌人数。必须覆盖密集拥堵、爆炸同发、重求电网和反复重开。硬件、负载、版本与采样条件一同记录。

## 9.12 结果判读

一条通关记录证明存在某条可行操作，不等于所有编成已平衡。少量内部试玩用于发现原因，不表述为统计胜率。优化不能改变真范围受击、资源守恒、死亡触发和元攻击排程。

当一种路线全面占优时，先查它是否没有支付宣称的空间、资源、时间或信息成本。解决的是缺失的取舍，不是为了凑克制表新增隐形抗性。
