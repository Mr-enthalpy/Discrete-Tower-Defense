# Discrete Tower Defense

一款正在设计中的俯视格子生存塔防：围绕核心经营生产、布置防线，在昼夜变化中应对敌人的组合与行动。

当前阶段是**仓库与设计基线**。已选择Windows桌面优先的Godot .NET＋C#技术路线，采用独立纯C#模拟核心；具体工具链组合待首次工程验证，没有可运行游戏、构建命令或已通过的游戏测试。

## 设计方向

- 高阶塔可由基础塔改建或组合，设施支持不同占地，至少包括1×1和2×2。
- 地形和邻接支撑分别影响建造、运行与开火。
- 单一建设/升级货币；能源实时生产与分配。本地无线交换与远程限流分开，可扩展储能昼夜调度。
- 真范围伤害完整作用于合法目标；敌人压力来自数量、质量和组织的共同作用。
- 行动组决定任务，共享导航提供方向，个体独立移动、接敌和受伤。

视觉以灰阶网格、符号化设施、几何敌群和清楚的战斗反馈为基础。玩法与美术由本项目独立设计和实现。

## 开始工作

```sh
git clone git@github.com:Mr-enthalpy/Discrete-Tower-Defense.git
cd Discrete-Tower-Defense
```

先阅读设计文档，再处理一个明确的工作项。下一个实现前置是验证并锁定Godot/.NET工具链与Windows导出；随后建立M0最小交战和规模探针。无线电网、多格实战塔、兵团战术与储能不需要同时塞入M0。

本次初始化只迁入本项目设计与协作文件，历史调查材料不作为构建依赖。项目许可尚未选定，本次没有添加许可证。
