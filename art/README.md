# 美术与音频

本目录预留项目资产，当前没有运行素材。开始制作后按需要建立 `source/` 保存可编辑原稿、`runtime/` 保存游戏使用的导出文件。

视觉依据见[项目启动框架](../docs/design/项目启动框架.md)的“美术风格规范”：灰阶地图、符号化设施、几何敌人，少量颜色表达状态；多格轮廓、朝向、支撑与能源覆盖必须清楚。

优先制作自有矢量、简单精灵和程序图形。首次导入资产时记录作者、来源、许可和导出方式；需要大型二进制时再配置相应版本管理策略。

技术路线采用SVG原稿、PNG图集/导入纹理与少量程序图形；Godot导入缓存不提交，导入设置和源文件保留。规则与呈现映射分开，批量实例仍对应独立敌人。打包目录、比例和性能约定见[技术架构](../docs/design/技术架构.md)。
