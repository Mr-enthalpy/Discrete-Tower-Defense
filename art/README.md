# 美术与声音

权威依据为[基线第 08 章](../docs/baseline/v1.0/08-美术、界面与声音.md)。二维构成主义＋功能主义，柔和细腻、符号化的构件语言；工业、神秘和污染连续演化，不沿用旧灰白极简/数学敌名方案。

未来 source 保存可编辑矢量、生成代码与参数；runtime 保存离线图集/音频等导出。资产记录作者、来源、许可、工具版本、参数与导出方式，确保可复现；引擎导入缓存不提交。

主轮廓和功能构件优先，少量线宽层级；C 调节相位/曲率/连接，P 调节 UI 装饰和 BGM 声部。界面骨架/热区保持稳定，技能实际信息锁由模拟驱动，特效不改碰撞或账目。元缄默不关闭警告音。辅助选项降低闪烁/抖动/强音效，不改变规则。

验收包含最小缩放、密集交战、甲盾、蓄能、缺电、预告、污染渐变与盲目期间可读性。标准资产不依赖原游戏素材；来客是单独扩展。
