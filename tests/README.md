# 验证

本目录预留真实测试。当前只有设计验收约定，没有测试框架、已运行用例或性能结果。

首批验证围绕M0的玩家结果与规则边界：命令执行完整性、单实体多格占用、独立受击、共享导航、运行许可和重开。完整循环、真群伤、地形改建、电网和兵团按阶段增加测试。

详细边界见[项目启动框架](../docs/design/项目启动框架.md)与[核心系统约定](../docs/design/核心系统约定.md)。采用xUnit验证纯C#规则，Godot headless检查集成，导出Release程序测完整性能；场景矩阵与暂定预算见[技术架构](../docs/design/技术架构.md)。首次实现后在这里说明真实运行命令，性能结果同时记录硬件、版本、负载和采样方式。
