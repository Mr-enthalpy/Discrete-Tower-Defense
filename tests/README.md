# 验证

当前 simulation/Program.cs 提供 29 项可执行检查和 --stress 探针；命令与实测结果见 [DEMO A](../DEMO-A.md)。后续系统用例仍是计划。[制作切片与验收](../docs/plan/制作切片与验收.md)登记真实规则的验证条件；实施后各编号链接到实际用例和结果，不把计划勾成通过。

simulation 放纯 C# 规则测试，integration 放 Godot 装配/资源/导出检查。规则运行器不依赖渲染，完整性能在 Windows Release 导出测量。重点包括比例公平、三种用能、雷击守恒、逐事件真 AOE、层盾、原子融合、Q 阈值、单族准备资格、C 维护及元技能恢复窗。

验证外部规则和边界，不为低风险文档或空接口造镜像测试；不以粒子预算、缓冲上限或近邻上限截断真实伤害。所有成绩记录版本、硬件和负载。
