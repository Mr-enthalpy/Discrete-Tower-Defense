# 游戏工程

本目录预留Godot .NET＋C#实现，没有可运行入口。后续在 `simulation/` 建立纯.NET规则库，`content/` 建立JSON加载库，`client/` 建立Godot宿主；依赖方向、工具链门槛和性能约定见[技术架构](../docs/design/技术架构.md)。

逻辑职责分为单局模拟、内容加载、表现与输入、平台接口。模拟拥有权威状态；输入提交命令，画面消费状态和事件。模拟不能引用Godot类型，不要求为每个职责建立一个Manager。

首个实现目标是[项目启动框架](../docs/design/项目启动框架.md)中的M0。多格实体、动作许可和行动组/共享导航的边界从M0保留；完整改建、电网、兵团战术和储能随后实现。详细规则见[核心系统约定](../docs/design/核心系统约定.md)。
